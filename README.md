# Swati Gavas — Personal Academic Website

A personal portfolio and academic website for **Swati Gavas**, a cosmology researcher. Built with React and deployed on GitHub Pages.

🔗 **Live site:** [swati-gavas.github.io/profile](https://swati-gavas.github.io/profile)

## Sections

- **About** — Background, education, and career journey from the Western Ghats to postdoctoral research at SJTU.
- **Research** — Tabbed overview of research areas: large-scale structure, halo/galaxy physics, cosmological tensions, numerical artefacts, and more. Includes links to publications.
- **SciPop** — Science popularisation: short stories, YouTube talks, and outreach efforts.
- **Gallery** — Image gallery with science illustrations, astrophotography, caricatures, and miscellaneous photos.
- **Contact** — Email, LinkedIn, YouTube, Goodreads, and CV download.

## Tech Stack

- **React 19** (Create React App)
- **Framer Motion** for animations
- **GitHub Pages** (`gh-pages`) for deployment

## Getting Started

```bash
# Install dependencies
npm install

# Run locally
npm start
```

The app will be available at [http://localhost:3000/profile](http://localhost:3000/profile).

## Deployment

```bash
# Build and deploy to GitHub Pages
npm run deploy
```

This runs `npm run build` followed by `gh-pages -d build`, publishing to the `gh-pages` branch.
